# 🚀 Featured Projects

### 🧠 FYNIX — AI-Powered Behavioral Focus Companion

A **desktop productivity companion** designed to help users manage tasks, plan focused work, run structured focus sessions, track productivity, and interact through voice.

**Key Features**
- 🎯 Structured focus sessions and real-time session tracking
- 📋 Task management and intelligent scheduling
- 🔄 Session recovery after missed or interrupted focus sessions
- 📊 Productivity analytics and focus insights
- 🎙️ Local voice interaction and voice check-ins
- ⚡ Real-time communication and presence tracking
- 🖥️ Windows desktop application with Electron

**Tech Stack**

`Electron` `React` `Node.js` `Express` `MongoDB` `Redis` `Socket.IO` `Python` `FastAPI` `Whisper` `Docker`

🔗 **Repository:** [FYNIX](https://github.com/Deepthi-M555/Focus-Companion-)

🎥 **Demo Video:** [Watch FYNIX Demo](https://youtu.be/F1C9Xlo0yO0)
